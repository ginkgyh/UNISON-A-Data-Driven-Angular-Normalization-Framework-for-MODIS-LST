# Format demonstrations

Each CSV contains three synthetic rows using the midpoint of the selected input scaler's training ranges and signed viewing angles −30°, 0° and +30°. These rows demonstrate the CSV schema and software execution only. They are not observed pixels, physical scenarios, model validation data or accuracy benchmarks.

For scientific inference, replace them with quality-controlled and temporally matched observations prepared using the study method. Temperature predictors are Celsius. Required fields depend on the selected model.
